# ShadowNet Cyber Labs — Banking Persona

Made by **Uzan Khan** — extended by Copilot

This branch turns ShadowNet into a realistic online banking portal ("ShadowBank") for immersive, ethical hacking practice. The web app exposes authentic-looking banking features (accounts, statements, transfers, statements preview, admin import tools) where the 15 challenges are embedded into real flows — not isolated challenge pages.

> ⚠️ Run this locally only. This repository intentionally contains vulnerabilities (SQLi, SSRF, XXE, command injection, LFI, deserialization, CSRF, etc.). Do NOT deploy to a public server or any shared/untrusted network. Keep it on 127.0.0.1 and run inside a sandbox (Docker recommended).

Quick start — local (Python):

```bash
git clone https://github.com/uzankhan/ShadowNet-Cyber-Lab
cd ShadowNet-Cyber-Lab
# optional: create a venv
pip install -r requirements.txt
# regenerate flags + DB (seed) then start
python3 scripts/seed_db.py
python3 app.py
```

Quick start — Docker (recommended):

```bash
# build + run
docker compose up --build
# open http://127.0.0.1:5000
```

What changed in this branch

- Banking persona: UI and templates will be adjusted to present an online bank (accounts, transactions, transfers, statements, admin tools).
- Flags are regenerated by scripts/seed_db.py on demand (default is to run it before starting the app). Flags remain in vault/secret but are randomized each seed so each run feels fresh.
- Hints: tiered hints are available in-app (3 levels). Hints are intentionally technical and do not provide full exploit steps; taking a hint deducts points.
- Progress tracking: per-session progress and challenge detection hooks are added (server-side progress table). When a flag is found and submitted, a congratulatory modal is shown.

Developer notes

- Run `python3 scripts/seed_db.py` before starting the app to (re)generate vault flags and the SQLite data used by the challenges.
- Configuration env vars (optional):
  - UNSAFE_MODE=1 to enable the most dangerous demo routes (deserialization endpoint, raw shell execution). Default is off.
