About ShadowNet Cyber Labs

ShadowNet Cyber Labs is a self-contained, offline training environment built for hands-on ethical hacking practice — the same feeling as a real bug bounty program or CTF, without needing to stand up your own vulnerable lab first.

There's no database here. Just files, sessions, and arrays — everything runs in-memory or from small local files, on purpose. This is a lab, not a production system.

15 flags are hidden across 15 real, working vulnerabilities: reflected XSS, IDOR, open redirect, SQL injection, command injection, local file inclusion, SSRF, a layered crypto puzzle, XXE, a race condition, CSRF, server-side template injection, insecure deserialization, a hardcoded secret, and business-logic price tampering. Nothing is simulated for looks — every exploit here actually works against the running server.

⚠️ Run this locally and offline. Do not deploy it to a public or shared network — every route in this app is intentionally insecure.
